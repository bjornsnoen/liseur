Reading positions now sync more reliably across devices, library search finds books across your entire collection, and translations can be saved in advance for offline reading. This release also introduces chapter recaps and story summaries in the Companion, adds context awareness and sentence return to read aloud, and lets you set translation and narration preferences per book.

### Reading

* The Story tab in the Companion now shows chapter recaps and a "So far" card summarizing the plot up to your current place without spoiling upcoming events ([#359](https://github.com/chmouel/liseur/pull/359)).

<img src="https://github.com/user-attachments/assets/803ab398-158f-4e0a-baf6-c2fc91aecaec" alt="The Story tab with chapter recaps and story so far summary" width="320">

* Character profiles and book mentions are now unified into a single Companion sheet, showing facts and relationships drawn from saved recaps before you send any lookups ([#360](https://github.com/chmouel/liseur/pull/360)).

<img src="https://github.com/user-attachments/assets/05ee9cf2-359e-41d7-a60d-6208c01bbd7e" alt="Character profile pane in the Companion sheet" width="320">

* Footnotes and links within the same chapter now open in a card over the text so you can read them and return without losing your place ([#368](https://github.com/chmouel/liseur/pull/368), [#369](https://github.com/chmouel/liseur/pull/369)).

<img src="https://github.com/user-attachments/assets/aa7b31ec-6b22-49cf-9872-3359587cefa6" alt="Note card displayed over the text without navigating away" width="320">

* Downloaded books can now be translated in advance for offline reading from book cover actions, with background progress, batching, pause/resume, and inclusion in ZIP backups.
* You can now tap the translation bar to change languages, translation services, and models directly from the reader, with the active model and service shown on the bar.
* AI translations can now include book context (title, author, chapter, and progress) from a customizable template to keep character names, terms, and tone consistent across pages ([#371](https://github.com/chmouel/liseur/pull/371)).
* Translation directions, glossaries, and Gemini narration styles can now be configured and saved per book.
* A "Back to the voice" button in the read-aloud player lets you jump straight back to the sentence being spoken after browsing ahead or behind.
* Read aloud can now send book context (title, author, chapter, and preceding sentences) to supported AI voices like OpenAI TTS models to help with tone, character voices, and pronunciation.
* The read-aloud player now displays the active speech service and model under the voice name.
* Ongoing read-aloud and translation sessions can be stopped directly from the reader's top-right menu.
* Added support for Gradium speech servers, including region selection and voice samples.
* Scrolling options ("Read by scrolling" and "Scroll the page for me") moved to the reader menu so you can adjust them without opening the appearance panel.

### Fixes

* Interrupted sync catch-ups now finish reading server history before marking the library as synced, preventing newer reading positions from being skipped or replaced by older echoes.
* In continuous scroll mode, navigation jumps, layout reflows, and opening the toolbar are no longer mistaken for reader scrolling or allowed to overwrite your saved position.
* Books replaced by a new file with the same name now fall back to their saved percentage if an earlier chapter ID is missing, allowing reading progress to continue saving.
* Books that list the same chapter twice in their reading order now preserve exact reading places.
* Sentences with spaces placed in separate inline spans or containing invisible soft hyphens now match correctly for on-page translation and read aloud.
* Paused whole-book translations now respect server retry-after headers on busy servers, hold back automatic resumption if your API key or server changed, and refuse to translate books into their source language.
* Gemini narration directions are now passed directly where the speech API reads them so the voice respects book-specific styles.
* Companion character searches, relationship parsing, and recap decoding now run off the main thread to prevent interface stuttering on long books.
* Fixed an issue where characters sharing an alias (such as a shared title) had their facts merged in Companion entries.
