Translate selected passages or whole books page by page, with translations saved on your device and restored when reopening. This release also introduces base-word definitions and Wiktionary translations, refines read-aloud resumption, locks the reading footer against stray taps, and adds a two-pane Settings view on wide screens.

### Reading

* Translate selected passages or the entire book page by page as you read. Translated sentences are cached on the device (up to 50,000 sentences) so revisiting a page or reopening a book returns the translation immediately without duplicate requests. Reopened books stay in translation mode with a faint corner indicator until stopped, and starting read-aloud or tapping Stop restores the book's original text. ([#306](https://github.com/chmouel/liseur/pull/306), [#308](https://github.com/chmouel/liseur/pull/308), [#309](https://github.com/chmouel/liseur/pull/309), [#313](https://github.com/chmouel/liseur/pull/313), [#315](https://github.com/chmouel/liseur/pull/315))

* The Define card can now display foreign-language Wiktionary translations via a button at the bottom of the card, opening full entries in that language when available.
* Read-aloud resumes near where playback was paused, repeating up to a second of audio to catch the context of the sentence instead of restarting the entire sentence or re-requesting speech audio. ([#304](https://github.com/chmouel/liseur/pull/304))
* The footer is now locked by default so accidental taps no longer change what it displays; long-pressing any corner or the center still opens the display menu. ([#321](https://github.com/chmouel/liseur/pull/321))
* Streamlined the text selection bar by turning Note and Define into icons, showing a single default highlight swatch, and moving Read aloud and Translate behind a More button. ([#320](https://github.com/chmouel/liseur/pull/320))

### Library

* Removed the reading stats home-screen widget, which struggled to stay in sync; the cover widget showing your current book remains available. ([#312](https://github.com/chmouel/liseur/pull/312))
* Library grids, series volumes, and reader lists now extend behind the system navigation bar with proper bottom padding so content is not cut off. ([#317](https://github.com/chmouel/liseur/pull/317))

### Fixes

* Added the missing API v1 version header to KOReader sync requests, fixing connection failures and HTTP 412 errors when pairing with the official KOReader sync server. ([#316](https://github.com/chmouel/liseur/pull/316))
* Handled predictive back gestures correctly when leaving the catalog browser from the saved catalog list. ([#317](https://github.com/chmouel/liseur/pull/317))
* Kept open settings screens up to date so choices such as highlight colors update immediately when altered. ([#318](https://github.com/chmouel/liseur/pull/318))
* Preserved footnote links within translated sentences, tracked reading progress properly in vertical books, and stopped translations from jumping ahead when turning pages quickly.
* Corrected placement of Wiktionary translation tables when entries split translations across separate pages.

### Under the hood

* On tablets, foldables, and wide windows, Settings now displays in a two-pane layout with the settings list on the left and the open page on the right. ([#317](https://github.com/chmouel/liseur/pull/317))
* External AI and speech servers, model names, and API keys are now consolidated on a shared "External services and API keys" page in Settings. ([#305](https://github.com/chmouel/liseur/pull/305))
